# 补丁

对**上游插件**的改动。上游都是 MIT，正确做法是 fork + PR，所以这里只放 diff。

## speak-up-目的模式.patch

给 `dsh-speak-up` 加"开口前先有个具体由头"的能力：

- 新增配置：`目的模式`、`目的用模型`、`每日上限`、`主人在聊分钟`
- 新增本地词库（关心 / 分享 / 好奇 / 续聊），最近 6 条不重复
- 真发时用一次很短的模型调用，从最近 8 条对话里想一句由头
- 两道硬闸门：主人刚说过话不打扰、今天开口到上限就停
- 状态文件 `~/.dsh/speak-up-purpose.json`

用法（在 fork 的仓库里）：

```bash
git apply patches/speak-up-目的模式.patch
```

> 补丁基于 `dsh-speak-up` 0.2.3。上游有改动时可能需要对一下上下文。
