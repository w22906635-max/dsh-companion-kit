# 风险与合规

> 这份文档比代码重要。**先看完再决定要不要用。**

## 一、封号风险

**自动化操作 QQ 账号是违反腾讯用户协议的。** 本仓库把 AI 接到 QQ 上，
用的是第三方客户端（NapCat），无论技术上多克制，**都存在被风控、被限制、被封号的可能**。

现实中的风险梯度（从低到高）：

| 行为 | 风险 |
|---|---|
| 只读：轮询收消息、本地生成 | 低 |
| 主动发**私聊**，频率低（小时级） | 中 |
| 主动发**群消息**、@ 人 | 高 |
| 高频发送、批量加好友、群发 | 很高 |
| 用主号做以上任何事 | **不要** |

**建议**：只用小号；把发送频率压到"像个人"的程度；
遇到"账号异常"提示立刻停手一周。

## 二、第三方软件

- **NapCat** 是第三方 QQ 运行时，与腾讯无关。
- 本仓库**不打包、不分发**任何 QQ 客户端二进制，请从官方渠道获取。
- 第三方客户端可能有自己的遥测/更新机制，**用之前自己看一眼**。

## 三、隐私

这套系统的数据都留在本机：

| 数据 | 位置 |
|---|---|
| QQ 消息 | 你配置的 NapCat 数据目录、DSH 会话日志 |
| 记忆 | `~/.dsh/fish-memory/` |
| 心情 | `~/.dsh/feiyu-mood/` |
| 密码（如使用） | `napcat-pw.txt`（建议只放 MD5） |

**但**：生成回复时，上下文会发给你配置的**模型 API**。如果你的模型服务商
不在本地，那么聊天内容对它可见。这一点无法通过改脚本解决，只能选服务商。

- 不要把人设、立绘、语音素材打包进公开仓库。
- AI 生成的内容由使用者负责。

## 五、本仓库不含什么

为了能公开，这里**故意不包含**：

- 任何真实 QQ 号、群号、昵称
- 任何 token / cookie / API Key
- 任何聊天记录、记忆卡片、角色人设原文
- 任何 QQ 客户端二进制

如果你 fork 后要提交改动，**提交前自己扫一遍**：

```bash
grep -rEn "[0-9]{6,12}|SESSDATA|sk-[A-Za-z0-9]{10,}|cookie|token" --include='*.json' --include='*.ps1' .
```
