# 部署

> 目标：从零到"QQ 里能跟她说话"，并且**开机不用管、掉线能自愈**。

## 0. 前置

| 需要 | 说明 |
|---|---|
| Windows 10/11 | 脚本是 PowerShell 5.1 兼容的 |
| Node ≥ 22 | NapCat 与 DSH 都要 |
| DSH（DeepSeek Harness） | 桌面版或 Web 版 |
| NapCat | 第三方 QQ 运行时，**自行从官方 Releases 下载**，别放本仓库里 |
| 一个不心疼的 QQ 小号 | 自动化有封号风险 |

## 1. 装 NapCat

1. 解压到一个**独立目录**（例：`D:\NapCat`）
2. 双击启动一次，扫码登录，确认 WebUI（默认 `127.0.0.1:6099`）能打开
3. 在 WebUI 里把 OneBot HTTP 服务开到 `127.0.0.1:3000`

**建议**：把密码的 MD5 写进 `D:\NapCat\napcat-pw.txt`，启动器会用"密码快速登录"，
不必每次扫码，磁盘上也不留明文。

## 2. 配好配置

```powershell
cd scripts\napcat
copy napcat.conf.example.json napcat.conf.json
notepad napcat.conf.json
```

```json
{
  "NapCatDir": "D:\\NapCat",
  "QQAccount": "123456789",
  "OneBotPort": 3000,
  "WebUiPort": 6099
}
```

## 3. 注册计划任务

```powershell
powershell -ExecutionPolicy Bypass -File scripts\register-tasks.ps1
```

会建两个任务：

| 任务 | 触发 | 作用 |
|---|---|---|
| `NapCat-Start` | 登录时 | 把 NapCat 拉起来（无窗） |
| `NapCat-Watchdog` | 每 5 分钟 | 巡检；进程没了就拉起；掉登录就退避重启 |

验证：

```powershell
Get-ScheduledTask -TaskName 'NapCat-*' | Select TaskName, State
Get-Content D:\NapCat\napcat-watchdog.log -Tail 5
```

## 4. 装上游插件

这几个**不在本仓库**，请按各自 README 装：

```bash
# 例子（命令随 DSH 版本可能不同）
dsh plugin --profile desktop add dsh-qq-bridge
dsh plugin --profile desktop add dsh-speak-up
dsh plugin --profile desktop add dsh-feiyu-mood
dsh plugin --profile desktop add dsh-fish-memory
```

装完重启 DSH，设置里应该能看到各自的设置页。

```powershell
# 把 plugins\group-chat 拷到一个你喜欢的位置，然后在 DSH 里：
# plugin_manager → install_bundle → 指向上面的目录
```

详细用法见 [../plugins/group-chat/README.md](../plugins/group-chat/README.md)。

## 6. 打通

1. QQ 桥设置里填：私聊对象 QQ 号、目标会话
2. 先**开试运行**跑几轮，确认它真的会发、内容没错
3. 再关掉试运行

## 7. 验证清单

- [ ] 关掉 DSH，QQ 里发一句话 → 发不出去（正常，桥没跑）
- [ ] 打开 DSH，QQ 发一句话 → 她回你
- [ ] 任务管理器结束 NapCat → 5 分钟内被看门狗拉起
- [ ] 故意让 NapCat 登录失效 → 日志里出现"半通…→ 重启"，而不是每 5 分钟刷一次二维码

## 8. 卸载

```powershell
Unregister-ScheduledTask -TaskName 'NapCat-Start' -Confirm:$false
Unregister-ScheduledTask -TaskName 'NapCat-Watchdog' -Confirm:$false
```
